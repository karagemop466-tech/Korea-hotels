# Hotel verification checklist

The published shortlist contains only curated property records that pass the data rules. It is not a substitute for checking live availability.

Before booking each hotel, verify on the official property page and record the date:

- [ ] Property name and address match the record
- [ ] Property is currently operating
- [ ] Exact room has one queen/king bed (not twin beds or a joined-bed configuration)
- [ ] Exact room has a private en-suite bathroom
- [ ] Exact dates are available
- [ ] Refundable and non-refundable totals were compared
- [ ] Taxes, fees, breakfast, and cancellation deadline were recorded
- [ ] Walking route to subway/KTX was checked in a map app
- [ ] Official direct price was compared with one OTA

## Gyeongju exception

Gyeongju has no approved property in the strict shortlist. The original five records did not satisfy the near-public-transport rule. Do not add a Gyeongju hotel until the exact property and room are checked. If the trip requires Gyeongju, the least-risk strategy is to keep it as a day trip from a transit-connected city, or explicitly relax the station-distance rule and document the taxi/bus plan.

## Evidence to capture

For each approved record, save the official URL, date checked, room name, bed description, bathroom confirmation, cancellation deadline, and total price. Recheck prices 30–45 days before arrival and again when booking.
